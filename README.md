# CBK Pension Towers independent sample

An independently created informational website sample. It is not operated by
or affiliated with the Central Bank of Kenya (CBK).

The site includes a Python standard-library HTTP server (`app.py`) and a
static preview (`preview.html`). CBK head-office contact details are included
as published on the official CBK Contact Us page; they are not represented as
a direct Pension Towers reception contact. Building-specific information and
visitor arrangements should be confirmed with CBK.

## Run locally

Install Python 3, open a terminal in this folder, then run:

```powershell
py .\app.py
```

Open <http://127.0.0.1:8000>. Stop the server with Ctrl+C.

You can also open `preview.html` directly in a browser.

Once GitHub Pages deployment completes, the public site is available at:
<https://pauldonaldke-rgb.github.io/cbk-pension-tower/>

# CBK Pension Towers independent sample

An independently created informational website sample. It is not operated by
or affiliated with the Central Bank of Kenya (CBK), and it is not the official
CBK website.

The site has a static, responsive landing page and a Python standard-library
HTTP server for local preview. The CBK crest is loaded from CBK's official
website; its use does not imply CBK endorsement. CBK head-office contact
details are not represented as a direct Pension Towers reception contact.
Building-specific information and visitor arrangements should be confirmed
with CBK.

## Run locally

With Python 3 installed, open a terminal in this folder and run:

```powershell
py .\app.py
```

Open <http://127.0.0.1:8000>. Stop the server with Ctrl+C.

You can also open `index.html` or `preview.html` directly in a browser.

Once GitHub Pages deployment completes, the public site is available at:
<https://pauldonaldke-rgb.github.io/cbk-pension-tower/>
